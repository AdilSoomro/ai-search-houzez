AI Search for Houzez — Documentation

Transform your real estate website into an intelligent conversational platform powered by natural language understanding.

Overview & Capabilities

AI Search for Houzez enables website visitors to search for properties in plain, everyday language (e.g. "Modern 4-bedroom villa with swimming pool in Coconut Grove under $2.5M"). The plugin translates their intent into structured WordPress taxonomy queries, renders live results in a split-screen preview panel with dynamic pagination, and allows interactive multi-turn refinements.

Houzez Theme Native Integration: The plugin directly utilizes your existing Houzez taxonomies (Type, Status, City, Area, State, Country, Features, Labels) and custom fields (Bedrooms, Bathrooms, Price, SqFt Area). No manual database migration required.

Key Features:

  • Natural Language Understanding: Parses price ranges, bedroom/bathroom counts, property types, features, square footage, and lease terms.
  • Location Intelligence Engine: Automatically resolves neighborhoods, cities, and abbreviations (e.g. "NYC" → "New York", "SoHo" → "Manhattan").
  • Multi-Model AI Backbone: Direct native support for OpenAI (ChatGPT), Anthropic (Claude), and Google (Gemini).
  • Interactive Tag Chips & Direct Dropdowns: Users can remove or click any active filter chip to adjust values on-the-fly without re-calling the LLM.
  • Dynamic Notice Synchronization: Conversational summary notice updates in real-time as users modify chips or apply refinements.
  • 1-Click Homepage Installer: Clones your active homepage, preserves existing sections, and inserts the AI Search Hero widget seamlessly.

Installation & Plugin Activation

How to install the plugin on your WordPress site running the Houzez theme.

  1. Upload the Plugin ZIP

    In your WordPress Admin Dashboard, navigate to Plugins → Add New Plugin → Upload Plugin. Choose the ai-search-houzez.zip archive and click Install Now.

  2. Activate the Plugin

    Once installation finishes, click Activate Plugin. You will see a new menu item labeled AI Search in your left admin sidebar.

  3. Activate License

    Go to AI Search → Activation tab. Enter your Envato Purchase Code / License Key to unlock all AI Search features, custom configuration panels, and official product support.

Entering API Keys & Provider Setup

Step-by-step instructions on obtaining and configuring your AI provider credentials.

To enable AI query processing, you need an API key from one of the supported foundation model providers. The key is securely encrypted and stored server-side in WordPress options (never exposed in client JavaScript).

How to Obtain API Keys:

1. OpenAI (ChatGPT / GPT-4o / GPT-5) openai

1. Visit platform.openai.com/api-keys.
2. Log in or create an account, then click Create new secret key.
3. Copy the key (starts with sk-... or sk-proj-...).
4. Paste it into the API Key field in the plugin and select OpenAI (ChatGPT) as the provider.

2. Anthropic (Claude 3.5 / Haiku / Sonnet) anthropic

1. Visit console.anthropic.com/settings/keys.
2. Log in to your Anthropic account and click Create Key.
3. Copy the key (starts with sk-ant-...).
4. Paste it into the API Key field and select Anthropic (Claude) as the provider.

3. Google (Gemini 2.0 / Gemini 3 Flash) gemini

1. Visit aistudio.google.com/app/apikey.
2. Click Create API key in Google AI Studio.
3. Copy the generated key (starts with AIzaSy...).
4. Paste it into the API Key field and select Google (Gemini) as the provider.

Verify Instantly: Always click the Test Connection button next to the API Key input. The plugin will execute a lightweight test payload and confirm whether your key is valid and active.

Primary Model vs. Lite / Fast Model Explained

Understanding the dual-model architecture and when to use each configuration.

AI Search for Houzez is architected with a dual-model system to deliver optimal natural language accuracy while maintaining rapid response times and minimal API operational costs.

Aspect Primary Model Lite / Fast Model
Role in Plugin Handles primary user natural language search queries, multi-turn conversational refinements, complex structured schema tool extraction, and personalized search explanations. Used for background sub-tasks such as fast query classification, real-time suggestion chip generation, and quick prompt rewriting.
Strengths Maximum reasoning depth, strict adherence to JSON tool calling schemas, accurate nuance detection (e.g. distinguishing between "waterfront" and "city view"). Ultra-low latency (<300ms), lightweight token cost, fast execution.
OpenAI Recommended gpt-5-mini or gpt-4o-mini gpt-5-nano or gpt-4o-mini
Claude Recommended claude-haiku-4-5 or claude-3-5-haiku-latest claude-3-5-haiku-latest
Gemini Recommended gemini-3-flash-preview or gemini-2.0-flash gemini-3.1-flash-lite or gemini-2.0-flash-lite
If left blank? Automatically uses the plugin's tested default for the chosen provider. Automatically falls back to the primary model or provider's lite default.
Tip for Most Websites: Leaving both model override fields blank is recommended. The plugin will automatically use the latest, cost-efficient, benchmarked models for your selected provider. Only enter a model name if you specifically wish to override the default (e.g. testing newly released LLM versions).

Field-by-Field Reference

Detailed explanation of every toggle, field, and control in the plugin dashboard.

1. Enable / Disable AI Search Switch Checkbox / Toggle
Option Key: ai_search_houzi_enabled Default: 1 (Enabled)

Master switch for AI Search. When enabled, users can execute natural language searches. When disabled, the frontend hero widget safely falls back to standard input or displays an informational message.

2. AI Provider Dropdown Select
Option Key: ai_search_houzi_provider Default: openai

Selects which AI company's infrastructure handles your search requests. Options: OpenAI (ChatGPT), Anthropic (Claude), or Google (Gemini). Switching providers adjusts the underlying API endpoints and tool calling schemas automatically.

3. API Key Password / Text Input
Option Key: ai_search_houzi_api_key

Your authentication key from OpenAI, Anthropic, or Google. Keys are masked with password bullets for privacy. To test whether the key works, click Test Connection.

4. Primary Model Override Text Input
Option Key: ai_search_houzi_model Default: Empty (Auto Default)

Allows specifying a custom model string if you wish to use a specific model version (e.g. gpt-5-mini, claude-haiku-4-5, or gemini-3-flash-preview). Leave blank to use provider defaults.

5. Lite / Fast Model Override Text Input
Option Key: ai_search_houzi_lite_model Default: Empty (Auto Default)

Allows specifying an ultra-fast, lightweight model string for sub-tasks (e.g. gpt-5-nano, gemini-3.1-flash-lite).

6. Custom System Prompt Guidelines Textarea
Option Key: ai_search_houzi_system_prompt Default: Empty

Allows you to inject custom business rules or domain guidelines into the AI prompt. For example:

Always prioritize properties in Miami Beach when users ask for coastal homes. When a user asks for luxury, filter max_price above $1,500,000 and include 'swimming-pool' feature.
7. Location Resolver & Custom Aliases Table / Key-Value Mapping
Option Key: ai_search_houzi_location_aliases

Maps colloquial names, regional nicknames, and abbreviations directly to real WordPress location taxonomy terms. For example, mapping "SoHo" → Manhattan (Area) or "The Big Apple" → New York (City).

Also includes a Location Misses Log, which tracks location queries entered by real users that were not found in your database so you can easily add aliases with one click.

8. 1-Click Homepage Installer Action Button / Installer

Automatically generates or updates an "AI Smart Home" page in Elementor containing the AI Search Hero widget with dynamic suggested search prompts, and sets it as your site Front Page (page_on_front).

Includes a "Preserve current homepage sections" checkbox: when checked, it deep-copies all sections from your currently active homepage and inserts the AI Hero cleanly at the top.

9. Rate Limiting & Safety Caps Number Inputs
Max Searches / User / Hour: ai_search_houzi_rate_per_user_hour (Default: 30) Max Searches / Site / Day: ai_search_houzi_rate_per_site_day (Default: 500)

Protects your website and API budget from abuse or scraping bots. User limits apply per IP address (or user ID when logged in). Site-wide limits ensure your monthly AI API spending stays under a predictable safety cap.

Troubleshooting & Frequently Asked Questions

Common issues and resolutions.

Q: "API Test Connection failed. What should I check?"

1. Ensure your API key is correctly copied without leading or trailing spaces.
2. Verify that your OpenAI, Anthropic, or Google Cloud account has active billing/credits enabled.
3. Check that your server firewall allows outbound HTTPS requests to api.openai.com, api.anthropic.com, or generativelanguage.googleapis.com.

Q: "Why does the search say 'No Matching Properties Found'?"

The AI accurately extracted the query filters, but your WordPress database currently has no published property matching that exact combination (e.g. 5 beds + specific neighborhood + price cap). Broaden your search or check your listing taxonomies in WordPress.

Q: "How do I reset my homepage back to default Houzez?"

In WordPress Admin, navigate to Settings → Reading, and select your original Houzez homepage (e.g. Home Default) under Homepage.
